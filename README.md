# Анализ задержек доставки (E-commerce)

Аналитический проект: разбираю, почему 40% заказов интернет-магазина
приходят с опозданием, и нахожу сегмент-виновник.

## Данные

Датасет о доставках E-commerce: 10 999 заказов, 11 признаков
(склад, способ доставки, звонки в поддержку, стоимость, скидка, вес и др.).
Целевой признак — `Reached.on.Time_Y.N` (1 = доставлено вовремя).

## Стек

- Python, Pandas, NumPy — разведочный анализ и расчёты
- Jupyter Notebook — ход исследования
- Power BI — дашборд
- Git / GitHub — версия и публикация

## Что сделано

1. Проверил(а) качество данных: пропусков и дубликатов нет.
2. Посчитал(а) базовые KPI и разрезы по складам, способам доставки,
   весу, скидкам и звонкам в поддержку.
3. Проверил(а) гипотезу о связи скидки и веса (кросс-таблица).
4. Собрал(а) Excel-отчёт с разрезами и Power BI дашборд.

## Главные выводы

- Вовремя доезжает 59,7% заказов; 40,3% — с опозданием.
- Опоздания сосредоточены в одном сегменте: **посылки 4–6 кг со скидкой
  до 10%** — там доходит вовремя лишь ~43%. Это 54% всех заказов.
- В сегменте «2–4 кг со скидкой от 10%» опозданий почти нет (99,9% вовремя).
- Скидка и вес коррелируют между собой: все заказы в диапазоне 4–6 кг
  имеют скидку до 10%. Причинно-следственную связь из данных установить
  нельзя — только наблюдаемую закономерность.
- Склад, способ доставки, пол и рейтинг клиента на пунктуальность
  не влияют (разница долей в пределах погрешности).
- Число звонков в поддержку растёт вместе с опозданиями (65% вовремя
  при 2 звонках против 52% при 6–7), но это следствие задержек, а не
  их причина. Звонки можно использовать как индикатор проблемного заказа.

## Рекомендация для бизнеса

Усиливать контроль не по складам и не по перевозчикам, а по сегменту
«вес 4–6 кг, скидка до 10%»: заранее помечать такие заказы как рискованные.
